# 开发路线与任务清单

## 1. 使用方式

编程智能体一次只领取一个任务编号。完成后给出：修改文件、设计说明、测试结果、遗留问题和下一推荐任务。除非任务明确要求，不跨越里程碑提前实现。

状态标记：`TODO`、`DOING`、`BLOCKED`、`DONE`。

## 7. 任务依赖规则

- 不先于 Schema 实现 Repository；
- 不先于 Repository 实现 Service；
- 不先于 Service 让 UI 直接操作数据；
- 不先于本地 Fixture 和 Dry Run 实现真实提交；
- 不先于事实校验实现自动生成最终材料；
- 不先于中断恢复测试启用人工审批流程。
